# Kristal Standard v7 draft.3.2 — DaaT boundary alignment

Date: 2026-10-03

This draft aligns the Kristal repository with the Interaction Kernel DaaT boundary while preserving the v7 architecture and the unchanged portable v6 contract.

- Human-facing name: **DaaT**.
- Machine identifier: `daat`.
- DaaT is optional and external to Kristal/Kristall conformance.
- DaaT admits and explicitly maps versioned external interactions into declared Kristal-native interfaces.
- DaaT does not own source acquisition/storage, general corpus normalization, mutable application state, KQ/KP/KA/KS identity, Mesh/axes/registries, or crystallization authority.
- Kristall remains the authority for v7 semantic identity and meta-orchestration.
- `kristal_state/6.0` remains the portable interchange contract unchanged.
- No active JSON Schema shape changed from draft.3.1.
