# Kristal Standard 7.0.0-draft.1 status — 2026-10-02

Kristal v7 is defined here as an additive meta-orchestration generation above the stable v6 portable state contract.

Frozen design decisions in this draft:

- spelling and roles: **Kristal** = portable unit, **Kristall** = encyclopedia/meta-orchestrator;
- existing v6 `kristal_state` remains valid and unchanged;
- v7 does not introduce a replacement `kristal_state` wire schema;
- v7 meta artifacts use `kristall_*` artifact types;
- generated portable projections use v6 plus `extensions.kristal_v7`;
- Mesh paths are not assertions;
- similarity is not equivalence;
- deduplication preserves provenance and is performed as factorization;
- orientation axes are first-class and projections use one primary plus at most one secondary axis;
- Surfaces are normally ephemeral views;
- structural promotions are auditable/supersedable;
- a reference relational/vector architecture is documented but not required.

Local schema/example validation is provided by `tools/validate_v7.py`.
