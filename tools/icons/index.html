Kristal Icon Generator

Assemble le code visuel Kristal : domaine en haut, nature au centre, maturité en bas. Génère des ICO Windows multi‑résolutions (16 à 256 px) et, au besoin, les PNG séparés.
v1.2 · 100 % local · sans dépendance

Aperçu

Nom de fichier
Chaque .ico contient 10 résolutions Windows : 16, 20, 24, 32, 40, 48, 64, 96, 128 et 256 px. Les aperçus 16–64 px sont agrandis à l’écran pour inspection. À 16–24 px, le rendu est volontairement simplifié.

Prêt.
Sur Chrome/Edge, le bouton écrit directement les fichiers dans un dossier choisi. Les ICO sont rangés dans ico/; les PNG optionnels dans un sous-dossier png/<taille> pour chacune des 10 résolutions.

Nomenclature

KR-{TYPE}-{DOMAINE1}[-DOMAINE2][-DOMAINE3]-M{0..5}.ico
Le domaine principal est toujours le premier. La taille n’est pas dans le nom du fichier ICO, car chaque ICO contient déjà toutes les résolutions.
