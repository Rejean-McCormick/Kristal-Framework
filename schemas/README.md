# Schemas

Canonical active machine contracts.

- `v6/` — portable `kristal_state` schema (unchanged compatibility substrate)
- `v7/` — Kristall semantic/meta-artifact schemas (unchanged v8 substrate)
- `v8/` — additive Language Layer and AI Query Layer schemas

The final v8 schemas make query scope, traversal, budgets, pagination, completeness and AI-context boundaries explicit. v8 does not require mutation of v6/v7 artifacts.
