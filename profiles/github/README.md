# Kristal GitHub Host Profile 1.0

Profile: `kristal.host/github/1.0`

This profile realizes v10 host bindings using GitHub repositories, Actions, Releases, Packages/GHCR, Deployments/Environments, Artifact Attestations and repository files.

The profile is operational only. GitHub identifiers do not participate in v9 logical/state commitments.

See `spec/v10/GitHub-Reference-Profile.md` and the companion one-time bootstrap tool.
