# Experimental unified private read contract 0.1 (V5.21.5)

The response envelope is an additive, opt-in contract, not a replacement for V11. Five explicit read modes are available: active index metadata, V11 candidate, structured native occurrence, registered native artifact, registered native record. Each mode has its own status and scoped key. Every result denies new authority, activation authorization and production integration. The active mode does not retrieve full active graph content. A V11 candidate assertion returns both the projection and original assertion, not a merged assertion. Native structured values are read through the 0.1 companion validator with exact original digests and Decimal decoding. Artifact readers return JSON without semantic promotion; non-JSON content is never returned or executed. Exact source digest and pointer remain authoritative for representation, not truth. Native record lookups return the record plus its full document context. No automatic external matching or editorial approval.

A Reader session assumes frozen private generation files, with a trusted report SHA supplied by the caller and the SQLite digest verified at session open; do not run concurrent writers. Original bytes used for individual results are rechecked on read. This is not a security sandbox for malicious installed code, nor a reader for live production workspaces. Preserve the prior generation directories. Compatibility with historical V11 readers is maintained by leaving all existing files and published contracts untouched.
