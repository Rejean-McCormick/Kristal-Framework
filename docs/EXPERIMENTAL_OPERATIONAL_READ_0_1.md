# Experimental operational-read/0.1

This additive reader is a private snapshot reader, not an authorization boundary or production service. It exposes the complete selected V11 graph or an exact scoped assertion only after the Manager qualifies the graph against the frozen active identity/lexical index and the pinned Kit/Framework. Existing V11 schema and tools are unchanged. A graph snapshot is not a live query or a claim of factual validity. A blocked workspace has no graph payload; its index metadata remains available explicitly. `active-only` refuses all non-active layer requests. `private-review` permits prior unified-reader envelopes with original status, native data and provenance unchanged; it does not promote them or infer any new status. These application-level guards do not replace OS access controls, domain reader policies or production integration. V11 graphs do not declare native epistemic status, so the assertion reader returns NOT_DECLARED_BY_V11_GRAPH. The graph digest and trusted report SHA bind the returned snapshot. Previous generations remain required.
