The former Runtime Pack byte-level gap is now closed under:

```text

```

Executable golden vectors now pass for:

```text
RP-002         PASS
RP-003         PASS
RP-004         PASS
RP-005         PASS
RP-005-NORUN   PASS
```

### RP-2 — Stable ordering

The implementation independently reproduces deterministic ordered JSONL bytes using the declared portable comparison rules.

### RP-3 — Row-group boundaries

`fixed_rows_100k` boundaries are deterministic and independently reproducible.

### RP-4 — Membership filter

KBF1 Bloom-filter bytes are deterministic.

The profile also verifies that Bloom false positives are only prefilter hits and are pruned against the authoritative store before semantic membership is accepted.

### RP-5 — Roaring bitmap

Canonical 32-bit Roaring portable serialization is deterministic with both:

- run optimization enabled;
- run optimization disabled.

The profile fixes deterministic container selection so semantically equivalent but byte-different serializations do not satisfy the same reproducibility claim.
