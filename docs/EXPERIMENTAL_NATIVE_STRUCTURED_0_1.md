# Experimental native structured representation 0.1 — proposal V5.21.4

This separate, opt-in companion contract is not a new adopted V11 graph datatype and does not change Framework VERSION, published V11 schemas, compatibility locks or the existing reader. `schemas/experimental/native-structured-0.1.schema.json` defines the packet and typed locator descriptors. `tools/v11/structured_native_v5214.py` validates the packet, every referenced original byte digest, registered artifact inventory and deterministic occurrence index. The original file bytes are the authority for the data representation, not the truth of the claims. JSON decoding refuses duplicate keys and nonfinite constants; decimals are decoded exactly in base 10. No canonicalization of native sets: sequence, duplicates and order remain as recorded. References with extra text remain references, not labels. Monolingual text retains the exact language tag, not inferred language. JSON objects and arrays remain structured, not text. The one exact Aging source hash/pointer is treated as a declared-kind/actual-shape anomaly, never repaired or retyped in the original. Other such mismatches are rejected. Qualifiers remain ordered, with their original envelopes. Full native assertion, status, evidence and provenance fields are returned together; evidence authenticity or truth is not certified. Occurrence IDs are SHA-256 of owner/source path/source digest/pointer, not KQ/KP/KA/KS. No external identity matching or semantic promotion. Non-JSON registered files are preserved as bytes only, never executed. A successful packet is a private representation qualification, not V11 conformance, editorial approval, canonical registration, or production reader integration. Adoption requires separate contract review and compatible consumers.
