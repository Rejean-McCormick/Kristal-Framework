# v8 TCK vectors

These vectors exercise the final v8 Language and AI Query contracts. They do not replace v6 or v7 vectors.

The v8 vectors cover composable lexicons, deterministic lexical stacks, rebuildable indexes, typed KQP requests/results, completeness/continuation metadata and semantic-atom AI context bundles.

A conforming v8 implementation must continue to pass all claimed v6/v7 conformance surfaces in addition to the applicable v8 profile.
