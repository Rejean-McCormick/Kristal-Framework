# Query

Kristal query surfaces expose selected assertions or derived projections under explicit reader/view policies.

Query does not decide truth and does not create new authority. It retrieves what the selected state, filters and reader policy permit.

## Useful query dimensions

A v6 query may filter or project by:

- referent / subject / predicate / object;
- assertion status;
- valuation dimension;
- value semantics / value state / value;
- coordinates;
- applicability;
- record role;
- actionability mode;
- evidence/source;
- validation or authority recognition;
- conflicts / supersession / lineage.

## Projection

A query can return a timeline, diagnostic candidate list, institutional path or other derived view. That view remains a projection of canonical assertions, not a parallel truth store.
