# Core invariants

```text
PATH != ASSERTION
SIMILARITY != EQUIVALENCE
ENTITY RESOLUTION != AUTHORITY
DEDUP != DELETION
DUPLICATION MAY BE GEOMETRY
PROJECTION != SOURCE
AXIS != TAG
AI PROPOSAL != ACCEPTED STRUCTURE
DISAGREEMENT SURVIVES COMPOSITION
SURFACE GAPS STAY GAPS
IDENTITY != LABEL
EXTERNAL_ID != KRISTALL_ID
RESONANCE != IDENTITY
RESONANCE != TRUTH
```
