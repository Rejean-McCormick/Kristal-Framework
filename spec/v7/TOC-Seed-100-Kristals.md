# TOC seed — 100 Kristals

`toc-registry-100-seed.example.json` is the first large seed for the Kristall TOC.

It contains:

- 100 Subject KQs derived from the supplied 100-Kristal index;
- a primary UNESCO microthesaurus placement for every Subject;
- an optional secondary placement where a Subject naturally crosses domains;
- the natural-angle text preserved from the seed index;
- two preferred native Axis Types per Subject.

These placements are **seed classifications**, not immutable ontology. They can be refined by exact UNESCO concept mappings, resonance, expert review and future KOSs while retaining the same Subject KQ identity.

The seed demonstrates the intended split:

```text
UNESCO category structure → where the Subject sits encyclopedically
Kristall Axis Type       → how the Subject is structurally explored
Kristal Projection       → one concrete Subject + orientation
```
