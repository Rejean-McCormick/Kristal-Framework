# Axis Types

The UNESCO Thesaurus answers primarily **what the subject is about**. Axis Types answer **how knowledge about that subject is organized**.

Axis Types are therefore native to Kristall, not imported from UNESCO.

## Relation to Orientation Axis

```text
Axis Type = reusable organizing grammar
Orientation Axis = concrete orientation used by a Subject/Projection
```

Example:

```text
Subject: Power in Canada / Quebec
Axis Type: Normative / decision
Orientation Axis: Legal authority
```

and:

```text
Subject: Power in Canada / Quebec
Axis Type: Agential / institutional
Orientation Axis: Informal influence
```

An Orientation Axis MUST declare one Axis Type. Multiple Axis Types can resonate with a Subject, but a portable projection still uses one primary and at most one secondary Orientation Axis.
