# Kristal Framework v7

Kristal v7 composes many v6 Kristals inside **Kristall** without changing their source identity. Core concepts: KQ/KP/KA/KS semantic IDs, Mesh, assertion families, resonance, orientation axes, Surfaces, projections and crystallization.

## Ecosystem boundary

Kristal/Kristall remains implementation-neutral and standalone. In Interaction Kernel deployments, **DaaT** (`daat`) may act as the optional admission/contract-mapping boundary in front of Kristal. DaaT does not own source acquisition/storage or Kristall semantic identity and crystallization. See [DaaT integration boundary](DaaT-Boundary.md).
