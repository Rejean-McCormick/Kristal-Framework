# Glossary

## Kristal
Portable domain-scoped structured state or generated projection.
## Kristall
Encyclopedic meta-orchestrator over many Kristals.
## Mesh
Typed cross-Kristal topology.
## Surface
Query-time oriented view.
## Projection
Materialized Surface exported as a Kristal.
## KQ / KP / KA / KS
Opaque Kristall IDs for entity, property, assertion and source.
## Semantic resonance
Context-bound vector of candidate alignment/dissonance signals.


## Category
A relatively stable encyclopedic navigation/classification region. Subjects may belong to multiple Categories.

## Subject
A semantic territory with stable KQ identity that can be projected under multiple orientations.

## Axis Type
A reusable native Kristall organizing grammar (for example spatial, normative, causal, flow, evidence).

## KOS
Knowledge Organization System. External thesaurus/taxonomy/ontology/classification registered for semantic alignment.

## Reference spine
The preferred external KOS used for default encyclopedic navigation. In draft.3 this is the UNESCO Thesaurus.
