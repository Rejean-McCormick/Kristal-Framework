# Kristal v10 Specification Status

Version `10.0.0-draft.3.1`.

Kristal v10 is an additive evolution above the frozen v6 portable epistemic state, v7 semantic identity substrate, v8 language/query layer, and v9 Semantic State Architecture.

V10 adds a **Hosted Kristal Network Architecture**: standard node discovery, host bindings, immutable publication records, directories, and host profiles. It does not replace or weaken v9 logical artifacts, state snapshots, commitments, materializations, authority, provenance, or Build → Publish → Activate semantics.

The first host profile is GitHub 1.0. GitHub is a reference host, not a semantic dependency of Kristal.
