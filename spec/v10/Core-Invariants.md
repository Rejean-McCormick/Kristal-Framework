# Kristal v10 Core Invariants

V10 inherits every v9 invariant and adds hosted-network invariants.

```text
LOGICAL STATE != PHYSICAL MATERIALIZATION
KNOWLEDGE != ASSERTION LIST
DOMAIN-NATIVE SHAPE != PORTABLE PROJECTION
SEMANTIC IDENTITY != CONTENT IDENTITY
LOGICAL COMMITMENT != BLOB DIGEST
REPRESENTATION != IDENTITY
REPACK != LOGICAL REVISION
COMPACTION != LOGICAL REVISION
ENCRYPTION CHANGE != LOGICAL REVISION
INDEX != SOURCE OF TRUTH
CACHE != AUTHORITY
RUNTIME PACK != CANONICAL STATE
DERIVED MODEL != CANON
SHARD != SEGMENT
STATE COMPOSITION != AUTHORITY MERGE
REFERENCE != OWNERSHIP TRANSFER
EPISTEMIC PROVENANCE != BUILD PROVENANCE
BUILD != VALIDATION
VALIDATION != AUTHORITY
INTEGRITY != AUTHORITY
ORDERED COLLECTION != SET
LOGICAL GRAPH != PHYSICAL MERKLE DAG
SOURCE BYTE CHANGE != LOGICAL CHANGE
PARTIAL AVAILABILITY != NEGATION
OPTIMIZATION MUST NOT SILENTLY CHANGE SEMANTICS
SMALL KRISTAL MUST STAY SMALL
HOST LOCATION != SEMANTIC IDENTITY
REPOSITORY != KRISTAL NODE
HOST BINDING != LOGICAL STATE
PUBLICATION RECORD != LOGICAL STATE
DIRECTORY != AUTHORITY
DISCOVERY != FEDERATION MEMBERSHIP
HOST ATTESTATION != EPISTEMIC AUTHORITY
AUTOMATION != AUTHORITY
HOST EVENT != LOGICAL MUTATION
PROFILE != CORE
MIRROR != LOGICAL REVISION
PUBLIC VISIBILITY != SEMANTIC AUTHORITY
PRIVATE LOCATION != SEMANTIC SECRECY
```
