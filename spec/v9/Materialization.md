# Materialization

A materialization is a physical representation of one logical artifact. Materialization profiles are explicit and replaceable.

V9.0 reference profiles are:

- `kristal.materialization/inline-json/1`
- `kristal.materialization/native-blob/1`
- `kristal.materialization/segmented-jsonl/1`
- `kristal.materialization/kristal-state-v6/1`

Factorization, dictionaries, segmentation, compression and encryption MAY change without changing the logical commitment when reconstruction is lossless. Local dictionary ordinals are never semantic identities.
