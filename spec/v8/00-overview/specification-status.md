# Specification status

Active standard baseline: **8.0.0**.

Kristal v8 is a final additive capability specification. The stable portable interchange artifact remains `kristal_state` `schema_version: 6.0`. The v7 semantic identity model and registries remain valid and unchanged.

The normative v8 surfaces are the Language Layer, AI Query Layer, semantic fingerprint/integrity rules, trust-boundary rules, schemas under `schemas/v8/`, compatibility contract and TCK vectors.

`8.0.0` does not declare v6 or v7 obsolete. It defines how a processor can add language and AI-oriented access while preserving their semantic contracts.
